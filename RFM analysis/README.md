This project performs an RFM analysis using the rfm table from the turing_data_analytics BigQuery database (https://console.cloud.google.com/bigquery?authuser=0&project=tc-da-1&d=turing_data_analytics&p=tc-da-1&t=rfm&page=table&ws=!1m5!1m4!4m3!1stc-da-1!2sturing_data_analytics!3srfm)

The goal is to understand customer behavior by analyzing Recency, Frequency and Monetary value for a 1-year period and segment customers for marketing strategy.
