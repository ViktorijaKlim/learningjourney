This project examines a multi-step user funnel to see how users move through each stage and where they drop off. It includes selecting events, building the funnel, calculating users and creating simple charts. The goal is to identify key problem areas and suggest improvements that could boost user engagement.

The data was extracted from a SQL database before being processed and analyzed.
