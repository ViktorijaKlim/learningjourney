This program allows the user to place two white pieces and up to 16 black pieces on a chessboard, then determines which black pieces can be captured based on valid chess moves.

The user enters pieces in a simple text format (e.g., rook a4, bishop d6).
The program validates all inputs, ensures coordinates are on the board and prevents incorrect piece names or early use of "done".
After all pieces are added, the program calculates and prints the list of black pieces the white piece can legally capture. If none can be captured, it reports that.
