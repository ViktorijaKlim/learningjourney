This project analyzes three fast food marketing campaign promotions using the wa_marketing_campaign dataset (https://www.kaggle.com/datasets/chebotinaa/fast-food-marketing-campaign-ab-test).
The goal is to determine which campaign performs best by running A/B tests and comparing the results.
