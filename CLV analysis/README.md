This project calculates Customer Lifetime Value (CLV) using weekly cohort analysis.
The analysis uses the turing_data_analytics.raw_events table and tracks all website visitors.
Users are grouped by the week they first appeared (registration cohort) and their spending is measured weekly to calculate Average Revenue per User (ARPU) and cumulative ARPU.
